# Bank Transactions ETL Pipeline (Python + SQL)

A small end-to-end project: take messy raw CSV files, clean and validate them with **Pandas**, load them into a **SQLite** database, and analyze them with **SQL**.

> All data is synthetic (generated by `generate_data.py`). No real customer information is used.

## What the pipeline does

1. **Extract** - reads `customers_raw.csv` and `transactions_raw.csv`
2. **Transform** - fixes real-world data problems:
   - dates in mixed formats (`2024-01-05`, `05.01.2024`, `05/01/2024`) -> one ISO format
   - amounts like `"1,234.50"` or `"123.4 UZS"` -> numeric values
   - inconsistent text (extra spaces, UPPER/lower case) -> standardized
   - duplicate rows, missing amounts, orphan records (transactions with unknown customers) -> removed and logged
3. **Validate** - assertions check unique IDs, positive amounts, no orphans
4. **Load** - writes clean tables into `bank.db` (SQLite)
5. **Analyze** - `queries.sql` contains 6 queries

## SQL skills shown in `queries.sql`
JOINs, GROUP BY / HAVING, CTEs, subqueries, window functions (`SUM() OVER`, `ROW_NUMBER()`), date functions.

## How to run

```bash
pip install pandas
python generate_data.py   # creates messy raw CSVs
python pipeline.py        # cleans + loads into bank.db
sqlite3 bank.db < queries.sql
```

## Project structure
generate_data.py   # creates synthetic messy data
pipeline.py        # ETL: extract, transform, validate, load
